## 2. Project Overview

### 2.1 Background

Meridian Healthcare Systems (“Customer”) has purchased the Northstar Enterprise Platform and requires professional services assistance with implementation, integration, and training. This Statement of Work defines the scope, deliverables, timeline, and fees for these services.

### 2.2 Objectives

- Configure and deploy Northstar Platform for Customer’s environment
- Integrate with Customer’s existing EMR system (Epic)
- Migrate historical data from legacy reporting system
- Train Customer’s staff on platform usage and administration
- Establish HIPAA-compliant data handling procedures

------------------------------------------------------------------------

## 3. Scope of Services

### 3.1 In Scope

| Phase | Activities |
|----|----|
| **Discovery** | Requirements gathering, technical assessment, project planning |
| **Configuration** | Platform setup, user roles, permissions, branding |
| **Integration** | Epic EMR integration via FHIR API, SSO configuration |
| **Data Migration** | Legacy data extraction, transformation, validation, loading |
| **Testing** | UAT support, performance testing, security validation |
| **Training** | Admin training (2 days), end-user training (3 sessions) |
| **Go-Live** | Production deployment, hypercare support (2 weeks) |

### 3.2 Out of Scope

The following items are explicitly excluded from this engagement:

- Custom feature development
- Hardware procurement or setup
- Network infrastructure changes
- Third-party software licensing
- Ongoing managed services (separate agreement required)
- Integration with systems other than Epic EMR
- Data migration from sources other than specified legacy system

### 3.3 Assumptions

This SOW is based on the following assumptions:

1.  Customer will provide timely access to systems, data, and personnel
2.  Customer’s Epic environment supports FHIR R4 API
3.  Legacy data is in a supported format (CSV, SQL export)
4.  Customer has dedicated project manager and technical resources
5.  Network connectivity between Customer and Northstar environments is available
6.  HIPAA Business Associate Agreement (BAA) is executed prior to work beginning
